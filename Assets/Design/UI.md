### 1.3 首次启动年龄/家长验证界面（00 · D22 / Compliance C1 新增）

> **定位**：全年龄英语学习 · 国内主市场路线下的**首次安装/未验证**阻塞流程，通过后才进 MainMenu。接口契约真源为 [Architecture.md](./Architecture.md) §4.12 `IAgeVerifyService`；**手机号仅用于年龄验证、不建账号/排行榜、不违反 D4**（例外口径见 Compliance §4 D1/D4）；本界面**无独立美术**（用 `ShelterHan` 渲染，美术资源需求表不新增资源）。

**主流程**（调 `IAgeVerifyService.VerifyAsync()` → 返回 `AgeVerifyResult`）：

| 步 | 界面/控件 | 方式 | 分支 |
|----|-----------|------|------|
| ① 说明页 | 全屏文案 + [开始验证] 按钮 | 声明仅用于年龄判定、不上传游戏数据 | 点击进入 ② |
| ② 一键登录 | 本机号码展示 + [一键登录] 主按钮 | `AgeVerifyMethod.CarrierOneClick`（客户端 SDK 直连运营商网关、不自建后端） | 超时/取号失败 → 转 ③ |
| ③ 短信验证码（备选） | 手机号输入 + [获取验证码] + 6 位码输入 | `AgeVerifyMethod.SmsCode` | 校验失败可重试 |
| ④ 结果判定 | 依运营商/实名返回展示 | `isMinor=false` → 通过进 01；`isMinor=true` → 转 ⑤ | — |
| ⑤ 家长同意 | 家长手机号 + 二次确认 | `parentalConsent=true` → 通过（未成年受限模式）；否则 → 退出 | 退出页（含合规说明文案） |

**状态与接口映射**：
- `IsVerified`（首启默认 false）→ 命中本界面；true → 直接进 MainMenu。
- `IsMinor` → 驱动广告分级（Compliance C5：未成年降级非个性化）与家长面板可用性（C8）。
- `HasParentalConsent`（成年恒 true）→ 未成年未获同意则阻断并走退出页。
- Phase 0 由 `MockAgeVerifyService`（`AgeVerifyMethod.Mock`）以弹窗 + 算术题/长按模拟；Phase 2–3 接入运营商号码认证 SDK。

**复用通用件**（§16）：`UIBtnPrimary`（主按钮）、`ConfirmDialog`（二次确认/退出）、`Toast`（验证码发送/失败提示）；本界面为独立全屏 Canvas，置于 Popup 层之上、不参与主流程图集。

**边界**：
- 本界面是全局**唯一**联网对外白名单口（运营商认证网关，见 TechStack §17），答题记录/掌握度**不经此接口**。
- 界面**不得**出现“登录/注册/绑定账号”字样（D4 无账号）；手机号输入框旁标注“仅用于年龄验证 · 不上传”。
- 适龄展示按 Compliance C9：对外分级 **12+/全年龄**（详见 §14 设置“适龄提示”行）。

## 2. 全局导航流

```
Bootstrap ─→ AgeVerify(00·首次安装/未验证阻塞) ─通过→ MainMenu(01)
   ├─ [开始游戏] → LevelSelect(02) ─点节点→ 详情(03) ─[开始挑战]→ (doctrineEnabled? Doctrine 04 → ) WordBankSelect(05) ─[确认词池]→ Battle(06/07)
   ├─ [词库选择] → WordBankSelect(05)（独立入口，改后回主界面）
   ├─ [避难所]   → Shelter(11) ─→ 建筑(12) / 武器(13)
   ├─ [词汇档案室] → Archive(14) ─→ 7日复习关 / 错题回溯关 / 大怪挑战关（→ Battle 同套 06/07）
   ├─ [商店]     → Shop(15)
   ├─ [纪录/成就] → Record(17)
   └─ [设置]     → Settings(16)
Battle ─ 胜利/失败 → Result(10) ─[下一关]→ LevelSelect | [再玩一次]→ Battle | [返回主界面]→ MainMenu
Battle ─ Android 返回键/ESC → 暂停(09)（等同暂停按钮）
```

- **进战前置链**：关卡详情 →（Doctrine 三选一，Phase 3）→ 词库确认。词库选择放**关卡之后**是因词池影响出题（§4.1）；主界面入口为独立快捷入口，两处共享同一 `WordBankSelectUI` 实例状态。〔建议，GDD 未定义顺序 → B-08〕
- **返回键策略**：Battle=暂停；Popup=关弹窗；全屏=回上一场景；MainMenu=双击退出（Toast"再按一次退出"）。
- **场景转场**：全幅淡入淡出 0.3s（DOTween Fade，§8.5.3"界面切换=淡入淡出+滑动"）。
