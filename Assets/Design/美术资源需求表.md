## 2. 命名规范（文件名=资源唯一 ID，禁止中文/大写/空格）

```
{类别前缀}_{主体}_[{变体}_{细节}]_{类型}{序号}.{ext}

角色类      zmb_norm_idle_01.png        fx_grenade_boom_07.png
UI 切片     ui_btn_bg_normal.png        图标         ic_crystal_64.png
场景        bg_city_far.png             Tilemap 瓦片 tm_city_ground_01.png
建筑        bld_wall_t3.png             武器         wp_rifle_t5.png
补给包      sup_pack_ice_icon.png       音频         bgm_battle_01.ogg / sfx_ui_click_01.ogg
图集        atlas_fx.spriteatlasv2      PSD 分层源   psd_zmb_norm.psd（导入 Spine 用）
Spine 工程  spine_zmb_norm.spine        运行时导出   zmb_norm.skel.bytes + zmb_norm.atlas + zmb_norm_Atlas01.png
```

| 规则 | 说明 |
|------|------|
| 类别前缀 | `zmb_`(敌人) `chr_`(玩家/NPC 角色 chr_gu 守卫者、chr_npc_*) `fx_`(特效) `ui_`(界面件) `ic_`(图标) `bg_`(背景) `tm_`(瓦片) `bld_`(建筑) `wp_`(武器) `sup_`(补给包) |
| 序列帧 | `_01.._nn` 两位补零，同动画同尺寸（±2px 抖动容差由 Tight Packing 消化） |
| 交付单位 | **角色/敌人**：Spine 工程 `.spine` + 导出三件套 `.skel.bytes`/`.atlas`/`_AtlasNN.png`（atlas page 由美术侧拼好）；**特效/UI**：仍按文件夹交付序列帧（`fx/…/`），入 Sprite Atlas 前由 TA 拼页 |
| 大小写 | 全小写；`?? 待解锁` 等 **纯文本符号由 TMP 字体渲染、不进美术表**（D21 M1 无贴图成本） |
| 符号/emoji | 💎★☆✓✗🔒▶🔊⚙ 等**可图形化状态符号一律走 `ic_*` 图标精灵（入 atlas_ui_main）**，禁系统 emoji 字体直显（兼解豆腐块与版权） |
| 字体资产 | `ui_font_cn_sdf`=`ShelterHan`（思源黑体子集）、`ui_font_lat_sdf`=`ShelterBaloo`（Baloo 2 子集，兼数字）、`ui_font_cjk_fb`=`ShelterHanFB`（近全量 CJK 后备防生僻字），**均 OFL 免费商用·已重命名**；DIN Alternate（商业）/Roboto Mono 弃用（TechStack §5.1 / Compliance §10） |

## 10. 交付与验收流程

1. **排单**：按"阶段"列切 P1（原型可灰模+本表 ★高 优先+**敌人 P1 批 9 种骨架：小 5/大 3/BOSS 1**，D23）→ P2（Alpha 全量+**敌人 P2 批 11 种**+提质资产）→ P3（Beta 增味：D18/D19/D20/D21 条目+**敌人 P3 批至满 30 种**+**BGM 全量重制/VO 转正**）→ P4（TwinWord 等）。
2. **命名校验**：提交前跑 Editor 校验工具（DevTasks 会话 B 附带）：小写/前缀白名单/尺寸上限/帧尺寸一致性。
3. **图集自检**：Sprite Atlas V2 页 ≤2048²、Tight Packing、跨图集误引零；Frame Debugger 抽查单界面 DrawCall。
4. **合规审**：全部玩家可见素材过 Compliance §6 软化清单（无血/无武器写实枪械造型→能量枪/绿雾消散）；D13 在 P3 提审前复审一轮 UI 内嵌文字。
5. **源文件**：PSD / Spine 工程 `.spine` / Ogg 工程入 Git LFS；Spine 导出三件套（`.skel.bytes`/`.atlas`/atlas page png）与序列帧/UI 导出物入对应 `Assets/Art/{子目录}`（目录规范见 ProjectSetup §3.5）。
