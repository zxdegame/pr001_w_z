## 1. 全局配置口径

### 1.2 波次与敌人全局规则（〔GDD〕）

- 每局固定 **5 波**，**BOSS 仅 1 只、固定第 5 波**（D3/D8）；教学关例外（1-1~1-4）。
- 标准波模板：**普通怪 3-5 只/波，大怪随机 1-2 只出现在第 2-4 波**（§4.2.4）；BOSS 波 = 普通 5 + BOSS 1。
- 波间隔 **5 秒**；波次切换：本波全部"被击败"或"到达能量墙开始攻击"即视为处理完毕（§2.3.3）。
- 敌人活力（基础武器攻击力 100、每发暴击 200）：**Normal 200 = 1 题 / Elite 600 = 3 题 / Boss 2000 = 10 题**；武器升级后答对数减少（附录 D：Lv.7 攻 200 → 大怪 2 题、BOSS 5 题）。
- 速度：Normal 1.0 / Elite 1.2 / Boss 0.7 m·s⁻¹（`Sprinter` ×1.5、`Wanderer` 0.6）。
- 战场几何（1920×1080，1m=100px）：0→1/6（3.2m）进场，**走廊 9.6m**，4/6（12.8m）停止攻墙；可答窗口 普 9.6s / 大 8.0s / BOSS 13.7s（D15 v2.6：全程正常推进、锁定目标高亮，买时间靠控制包）。
- 游走怪（D20）：每关 `WandererSpawnChance=0.05`、限第 2-4 波、每局 ≤1；不计入通关判定。
- 补给包保底（D16）：每关 ≥1 控制 +1 转化；**BOSS 波必掉 1 控制**；教学/复习/错题关豁免。

### 1.3 词池与出题数口径

**单关出题数容量（= 各敌人在基础武器下的答对数总和，〔推导〕）**：
```
出题数容量 = Σ(普通×1 + 大怪×3 + BOSS×10)     // 武器升级后实际出题数下降
```

**初始词池规模**：`初始词池 = 出题数容量向上取整至 5 的倍数`〔建议〕，并保证 ≥10（低于 §4.1"词池 <10 自动补充"阈值前不触发补充）；来源比例按 §4.1：待复习 40% / 错题本 30% / 新学 20% / 词池新词 10%（不足互相补位）。

**星级"答对率"分母**：旧 GDD 口径为 `答对题数 / 初始词池数`（§6.4.1）。逐关核算后发现**标准配置下全击杀也无法接近 90%**（如 2-1 满分仅 40/50=80%，三星不可达）。→ **A-02 已定案（GDD v2.9 §6.4.1）**：分母改为 **本局实际首次出题数**（首次答对+首次答错+首次超时，重试不重复计），新增 `GameData.questionsIssuedFirstTimeInBattle` 字段；本文档星级预估均按此口径。

### 1.4 星级判定（〔GDD〕D12 / 附录 D，全关卡统一）

| 星级 | 条件（必须同时满足） | 奖励系数 |
|------|----------------------|----------|
| ★★★ | 耐久百分比 > 80% 且 答对率 > 90% | 1.5 |
| ★★☆ | 耐久百分比 > 50% 且 答对率 > 70% | 1.2 |
| ★☆☆ | 通关且耐久 > 0 | 1.0 |
| 失败 | 耐久 ≤ 0（0 星） | 0.5 |

耐久上限 = 能量墙阶位（1 阶 100 … 5 阶 500），每局重置满值（D9）。

### 1.5 奖励公式（〔GDD〕附录 D 为唯一真源）

```
基础产出 = 普×1 + 大×2 + BOSS×5      （能量晶，全局唯一货币）
           普×0.5 + 大×1 + BOSS×3     （武器碎片，升级材料非货币，取整规则见 §7 A-11）
最终 = 基础产出 × 星级系数 × (首通? earlyChapterBonus 1.3 : 1) + §6.1 首通额外奖励 + D21 里程碑晶（如有）
重复通关：固定 能量晶 5-10；5% 稀有道具、10% 记忆卡；失败仅 50% 击杀基础〔v2.9：旧"金币"列系输入错误已删除，无第二货币〕
```
