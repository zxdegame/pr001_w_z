## 0. 阅读顺序与决策依据

本文件是“**全年龄定位 + 国内主市场（版号前灰区测试 / 版号后正式上市）+ 纯广告**”路线的**唯一合规真源**。任何上架/内测分发、广告 SDK 接入、未成年人与家长验证，都以本文为准。若与 ProjectSetup.md §11.6 / TechStack.md §16.5 有冲突，以本文为准（更新最近）。

**核心决策**：

| 项 | 决定 | 理由 |
|----|------|------|
| 定位 | **全年龄英语学习**（非儿童向，与 GDD §1.3 “8-35 岁”、D14 “小学→四六级”一致） | 不再按儿童向 App 做强制非个性化广告/COPPA 处理；但仍需对未成年用户做国内法定保护（见 §2） |
| 平台 | Android + iOS 移动 App（**锁定横屏**） | 放弃小游戏三端（微信/抖音/团结），包体/持久化/审核成本过高 |
| 版号 | **本版不开（无预算）→ 融资后申请** | 版号申请周期 3-6 个月需资金；本版靠灰区内测积累数据去拿投资，拿到后申请版号正式上市 |
| 市场 | **纯国内主市场**（放弃海外发行） | 版号前灰区内测（TestFlight + 安卓官网 APK）；版号后国内安卓商店 + iOS 中国区正式上市 |
| 类目 | 休闲益智（游戏） | 版号后按休闲益智游戏国内上架；教育类目仅作规避版号的备选路径（见 §1.2） |
| 变现 | **纯广告**（0 内购）；商店保留但**只收能量晶**；全年龄可投个性化广告 | 无版号不能开放 IAP；广告接入路径成熟；能量晶不可用钱换（GDD §12 D1）；⚠ 版号前灰区阶段广告收入极低（仅技术验证） |

## 1. 发行渠道矩阵（版号前灰区测试 / 版号后国内上市）

### 1.1 目标渠道清单（纯国内·双阶段）

> **路线**：本版（无版号）**不提交任何应用商店**，只做 **iOS TestFlight + 安卓官网 APK/蒲公英** 灰区内测；拿到投资后**申请版号**，再上 **iOS 中国区 + 国内安卓商店** 正式上市。**已放弃海外发行**；Steam/PC 暂缓。

| 渠道 | 版号前（本版） | 版号后（融资后） | 需要材料 | 备注 |
|------|:---:|:---:|------|------|
| **iOS TestFlight** | ✅ 主测试分发 | 持续 | Apple Developer $99/年 | 版号前 iOS 唯一免商店审核分发（≤ 1 万人/120 天） |
| **安卓官网 APK / 蒲公英 / fir.im** | ✅ 主测试分发（灰区） | 补量 | 无（自签名） | 版号前安卓唯一免商店分发；不提审商店=无版号可行；需告知用户非商店渠道风险 |
| **TapTap** | ⚠️ 独立游戏可先测 | ✅ 正式上市 | 版号（商业化） | 可作版号前合规测试补充（非商业分发） |
| **App Store 中国区** | ❌ 不上 | ✅ 正式上市 | **版号** + ICP 备案 + 软著 | Apple 2020 起对中国区游戏实质要求版号 |
| **国内安卓商店**（华为/小米/OPPO/vivo/应用宝） | ❌ 不上 | ✅ 正式上市 | **版号**（强制）+ 各商店资质 | 无版号一票否决 |
| **海外 App Store / Google Play** | 🚫 本版不做（已放弃） | 视融资后战略再评 | — | 纯国内路线，不投入海外本地化/合规 |
| **Steam / PC** | 🚫 暂缓 | 待商业模型明确 | — | 与移动纯广告变现冲突，后置评估 |
| **微信/抖音/团结小游戏** | 🚫 已放弃 | — | — | 包体/持久化/审核成本过高（旧决策） |

### 1.2 备选：iOS 中国区走"教育类"路径

**动机**：若**融资/版号前就要国内公开获客**（不等版号），可考虑**放弃游戏类目、改走“教育” App** 上架（教育类目在国内上架不需版号，但需 ICP 备案与去游戏化）。与主路线（等版号后按游戏上市）互斥，属备选。

**要求**：
- ICP 备案（国内主体，1-2 个月）
- 教育类目资质承诺（自证非游戏）
- **去除所有"游戏化"字眼**：关卡 → 练习；战斗 → 训练；得分 → 掌握度；BOSS → 大魔王（还是敏感）
- 变现受限：Apple 教育类目对广告审查严格，可能只允许"订阅制"

**评估**：改动量大、影响玩法呈现，**Phase 3 前不启动**。仅作为**用户增长受阻时的兜底**。

## 2. 未成年人与家长合规清单（全年龄产品仍适用国内未成年人保护）

> **定位说明（v1.11）**：产品已改为**全年龄英语学习**（非儿童向），不再按 COPPA/Apple Kids 做强制非个性化广告处理；但因用户含未成年（GDD §1.3 “8 岁起”），**国内未成年人保护法定义务仍适用**。且本版为**国内主市场（放弃海外）**，以下列适用法规以国内为主。

**适用法规**：
- 《中华人民共和国未成年人保护法》（2021 修订）——适用
- 《儿童个人信息网络保护规定》（2019）——14 岁以下儿童信息仍适用
- 《个人信息保护法》（2021）——适用
- 《移动互联网未成年人模式建设指南》（2024 征求意见稿）——适用
- 国家新闻出版署防止未成年人沉迷网络游戏规定（**2021 史上最严防沉迷**）——**需版号且接入官方实名验证系统，后置至版号阶段**
- ~~Apple App Store Kids Guidelines / Google Play Families Policy~~——**因放弃海外发行不再适用**（版号后 iOS 中国区按国内审核）

## 3. 广告变现合规清单（10 项，纯广告路线核心）

### 3.1 广告 SDK 与合规配置

| 项 | 适用 | 合规要求 | 实现要点 |
|----|------|-------------|---------|
| **穿山甲**（国内主） | 本版灰区测试 + 版号后国内上市 | 全年龄默认正常（个性化）广告；对**已识别未成年用户**切儿童安全等级/非个性化 | `PangleAdsService`；运行时按 C1 年龄结果切换 `childDirected`；**激励视频发的补给包只能为非必需增益，过关必需包不得依赖广告** |
| **优量汇**（国内备） | 同上 | 同上 | 与穿山甲二选一/竞价，运行时开关 |
| **运营商号码认证 SDK**（C1） | 本版 | 仅用于年龄/家长验证、**非广告**、不采集游戏数据 | 客户端直连运营商网关，不自建后端（TechStack §17 验证白名单） |
| ~~Google AdMob / Meta Audience Network~~（海外） | 🚫 本版不做 | — | **因放弃海外不再集成**；若回评海外再按当地法规重启 |

### 3.2 广告位与频率

| 规则 | 上限 | 理由 |
|------|------|------|
| 单局广告次数 | 成年无硬上限（建议 ≤3）；**未成年 ≤ 1 次** | 全年龄主定位；《未保法》对未成年网络保护 |
| 单日广告次数 | 成年无硬上限；**未成年 ≤ 5 次** | 未成年人保护法 + 行业最佳实践 |
| 广告类型 | 仅 **激励视频**（Rewarded Video） | 插屏/Banner 体验差、易诱导 |
| 广告触发时机 | **答题过程绝不弹广告**；仅限失败结算、每日奖励翻倍、补给包刷新 | 保护心流 + 符合"非诱导"原则 |
| **技能包广告红线（GDD §12 D16）** | 过关必需包来自广告 = **0** | 过关所必需的技能包**只能靠游戏内掉落**；激励视频只能发非必需增益包，不得构成“不看就必输”的必需包来源（避免变相付费墙/诱导） |
| 广告内容过滤 | 成年：默认；未成年：开启**儿童安全等级**（穿山甲亲子类目） | 未成年排除暴力/赌博/恋爱/购物广告 |
| 广告默认开关 | 成年：默认开；未成年：默认关（家长面板可开） | 分级控制 |
| 广告 SDK 初始化 | 游戏启动时异步初始化，失败不阻断 | TechStack §17 联网边界 |

### 3.3 变现与商店边界（GDD §12 **D1 已定案**）

- **0 内购**（IAP）：无版号无法开放；避免家长被误扣；不引入 `com.unity.purchasing` / App Store IAP / Google Play Billing
- **商店界面保留**：商店作为一个 UI 与玩法入口**不删除**，但它是**纯本地消耗系统**
- **物品只能用能量晶购买**：词库解锁、道具、建筑升级等全部以能量晶计价（`PurchaseCurrency` 只有 `EnergyCrystal` 一个枚举值）
- **能量晶不能用钱换**：无充值入口、无“兑换能量晶”、无服务端下发；只能通过答题结算与激励视频获取
- **界面禁止出现**：`$` / `¥` / 价格标签 / 充值入口 / 购买去广告 / 抽卡 / 开箱 / 季卡通行证
- **广告收入**：预期 eCPM 国内 ¥30-60、海外 $3-8（激励视频）
- **提审口径**：App Store Connect / Play Console 的 IAP 列表必须为**空**；Data Safety 与隐私标签按 §4 不采集口径填写

> 实现约束：`IStoreService`（Architecture.md §4.11）；Phase 2 商店 UI 完成后，用 §6 词表跑一遍 UI 文本断言（参 ProjectSetup.md §9.3）。

## 10. 素材与字体授权（**不买字体/美术版权路线**）

> 项目方定策：**不买字体版权** → 一切字体/美术/音频素材必须来自 **原创** 或 **免费商用开源许可（SIL OFL / Apache 2.0 / CC0 / 明确可商用）**；禁用任何需购买授权才能嵌入的素材。本节为字体与素材授权的唯一合规真源（选型技术口径见 TechStack §5/§5.1）。

### 10.1 字体许可证矩阵

| 字体资产 | 来源 | 许可证 | 不买版权可用 | 合规处置 |
|----------|------|--------|:---:|---------|
| `ShelterHan` SDF | 思源黑体 / Noto Sans CJK | **SIL OFL 1.1** | ✅ | 子集化后**重命名**（避开保留名 RFN） |
| `ShelterBaloo` SDF | Baloo 2 | **SIL OFL 1.1** | ✅ | 兼作数字字体；子集化后**重命名** |
| ~~DIN Alternate~~ | Monotype/Linotype 授权；macOS 自带 DIN Alternate 属 Adobe 授权版 | ❌ 商业专有 | 🚫 | **禁用**（需购买）；数字已并入 ShelterBaloo |
| ~~Roboto Mono~~ | Google Fonts | Apache 2.0 | ✅ | 自愿弃用（非版权问题，为减字体套数） |

### 10.2 OFL 履约清单（虽免费仍必守，否则审核/法律风险）

- [ ] **重命名**：子集化/转 SDF 属修改，**不得沿用保留字体名**（Source Han/Noto/Baloo），统一改 `ShelterHan`/`ShelterBaloo`/`ShelterHanFB`（GDD/TechStack/美术表口径一致）；**改名强度以各字体 OFL 头 RFN 声明为准**（Baloo 2 声明保留名必改；思源/Noto 未声明时改名属可选，本项目一律改名取保守姿态）
- [ ] **随包附 `OFL.txt` 许可全文 + 版权声明**（放游戏内“关于/开源许可/素材清单”页，**UI.md §14 设置页已登记承接**，与附录 A 隐私政策入口同层）
- [ ] **不单独售卖字体本身**（仅嵌入 App，不触发）
- [ ] **留存下载来源 URL + 许可快照**归档（备 Apple/Google 索取授权链）
- [ ] **生僻字/缺字自检**：遍历全部本地化字符串字符集 ∩ 字体 characterSet，无豆腐块方可提审（Phase 3 提审前必过）

### 10.3 全素材授权总红线（字体之外一并适用）

- **美术/图标/特效**：一律原创或 CC0/可商用；**符号/emoji 走自制 `ic_*` 图标精灵**，禁嵌 Apple/Google 专有 emoji 字体（自带版权风险）。
- **音频**：BGM/SFX 原创或免版税可商用（登记来源）；单词发音 TTS 需确认商用条款。
- **第三方 SDK**：开源库许可证登记（UniTask MIT、DOTween 内置版等），与 §4 隐私声明并行。
- **上架自检**：提审前输出一张《素材来源与许可证清单》，逐项可自证。
