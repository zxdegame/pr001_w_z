## 1. 游戏概述

### 1.1 游戏简介
<!-- 参考文档：世界观.txt -->

> 2077 年「雾语灾变」爆发，失控的 AI 词汇发生器释放特殊灰雾席卷城市。玩家作为仅存的「词汇守卫者」，手持词汇能量供能的速射武器，通过正确回答英语单词题目激活武器能量核心，击败被无效词汇碎片附身的小怪兽，守护避难所防线。

**核心概念**：一款将英语单词学习与射击塔防玩法深度融合的教育游戏，通过答题驱动战斗，帮助玩家在游戏过程中自然记忆英语单词。

**游戏卖点**：
- 创新玩法：英语答题 + 射击塔防，学习娱乐两不误
- 科学记忆：融入 7 日记忆法，系统化帮助玩家巩固单词
- 丰富词库：覆盖小学到四六级全阶段，支持多版本教材选择
- 策略深度：连击系统、特殊补给、防线升级，玩法多样

### 1.2 世界观背景
<!-- 参考文档：世界观.txt -->

2077 年，全球爆发「雾语灾变」。失控的 AI 词汇发生器泄漏的特殊灰雾席卷城市，普通小怪兽被雾中携带的无效词汇碎片附身，变得异常危险。只有正确的英文单词释义才能激活武器里的「语言能量核心」，击穿雾层对小怪兽的强化 buff。

玩家扮演仅存的「词汇守卫者」，手持靠词汇能量供能的速射武器，站在避难所防线前，持续向小怪兽射击。小怪兽从屏幕左侧出生，向右侧的避难所推进。防线上的词汇能量墙会实时显示需要回答的单词，玩家需要在四个答案按钮中选择正确答案，答对后词汇守卫者射出带有词汇能量的子弹击败小怪兽。

## 2. 核心玩法

### 2.1 玩法概述
<!-- 参考文档：战斗流程.txt、选词流程.txt -->

> 玩家选择英语词库后进入关卡，小怪兽从屏幕左侧分批出生向右侧避难所推进。自动哨塔会持续射击小怪兽，但伤害较低，只能减缓小怪兽前进速度。当小怪兽进入答题触发圈时，屏幕弹出英语单词考题，玩家答对即可射出带有词汇能量的能量弹，直接击败当前普通小怪兽（基础武器下普通怪一发暴击即倒，§12 D8）；答错则小怪兽仅停顿并刷新 new 题目。通过连续答对触发连击 buff，利用特殊补给和防线建筑抵御小怪兽进攻，保护避难所防线。

**核心玩法**：英语答题驱动射击战斗 + 塔防策略防御 + 7 日记忆法学习系统

### 2.2 词汇系统

#### 2.2.1 词库分类

> **解锁规则（与 §7.5.2 / 附录 D 一致）**：达到下表“解锁条件”的**掌握度门槛**只是取得购买资格，仍需在**能量晶商店**消耗能量晶才能启用（**能量晶不可用钱买**）。两者是“前置资格 + 本地支付”双门槛，无任何真实货币参与。

| 词库阶段 | 包含内容 | 解锁条件 |
|---------|---------|----------|
| 小学词库 | 1-6 年级英语词汇（人教版、外研社版、译林版、苏教版） | 默认解锁 |
| 初中词库 | 7-9 年级英语词汇、中考高频核心词 | 累计掌握 500 词 |
| 高中词库 | 高一到高三词汇、高考 3500 考纲词 | 累计掌握 1500 词 |
| 四六级词库 | 四级/六级真题词汇、听力高频词、阅读核心词 | 累计掌握 3000 词 |
| 专项词库 | 动物、文具、食物、家庭成员等场景词 | 根据阶段解锁 |

> **首发包内置范围（§12 Q7 定案）**：首发安装包**必须包含小学、初中、高中、四六级四个年级阶段的全部核心词库**；教材版本**首发仅内置人教版 + 外研社版**，其余版本（译林 / 苏教 / 牛津等）走后续资源包（DLC）下载。**包体硬约束为 ≤200MB（§12 D23 修订 D14：原“词库数据 >80MB 豁免”条款作废，词库数据全额计入 200MB）**，口径见 TechStack.md §9。

#### 2.2.2 词汇掌握机制

| 状态 | 说明 | 判定标准 |
|------|------|----------|
| 生词 | 首次遇到的陌生单词 | 答错后自动入库 |
| 学习中 | 开始记忆的单词 | 答错 2 次以上进入错题回溯室 |
| 已掌握 | 熟练掌握的单词 | 累计答对 3 次 |
| 长期掌握 | 完成 7 日记忆周期 | 完成第 7 天复习挑战 |

#### 2.2.3 词汇能量晶
- **获取方式**：答对单词掉落、关卡奖励、激励视频（7 日复习完成也给晶）；每日任务产出属 **Phase 4+**（§12 D4，本版不接入）
- **不可获取途径**：**不能用真实货币购买或充值**（§12 D1）；无任何服务端下发
- **用途**：解锁词库、升级防线建筑、购买道具
- **产出平衡**：普通小怪兽掉落 1 晶，大怪兽掉落 2 晶，BOSS 掉落 5 晶 + 首通稀有道具×1（数值后期按爽感调整）

#### 2.2.4 自主学习系统（单词三会）

> **与 §12 D8 的一致性**：本版**基础攻击即“答对=必定暴击”**（每次答对都按攻击力×200% 造成暴击伤害），因此武器表**不再设随机“暴击率”属性**；Lv.4「会心一击」是在此基础上对**下一次**答对的额外增伤。

> **触发方式（§12 D17）**：武器技能均为**答对触发的射击强化模式**（“冷却”=可用间隔，**非自动开火**）：快速射击=冷却结束后接下来 3 秒内每次答对连射；穿透/激光/等离子/词汇风暴=答对时把**该次暴击**按直线/范围/全屏扩散为多个“答对暴击实例”。**任一武器技能都不产生脱离答对的自动伤害**（与 §12 D8/D16 铁律一致，`TakeDamage` 仍只由“答对”结算调用）。

##### 五、武器外观定制

**可定制部件**：
- 枪管：不同形状和颜色
- 枪身：材质和纹路
- 能量核心：发光效果和颜色
- 瞄准镜：样式和特效
- 枪托：形状和装饰

**外观获取方式**：
- 武器升级自动解锁对应外观
- 特殊活动限定外观
- 成就奖励独家外观

       ↓

       ↓

#### 2.3.3 战斗规则

| 规则项 | 说明 |
|--------|------|
| 胜利条件 | 击败所有波次小怪兽（共 5 波），且**词汇能量墙未被摧毁**（能量墙耐久值 > 0） |
| 失败条件 | **能量墙耐久值归零（<= 0）→ 能量墙被摧毁 → 避难所失守，本局直接失败**（唯一失败判定） |
| 耐久主体 | **避难所本身没有血量 / 耐久值**；全场唯一的防线数值是「词汇能量墙耐久值」（§2.4.3），小怪兽攻击的一律是能量墙 |
| 答题时限 | 单题默认 10 秒，可手动调整 10-20 秒区间（通过设置界面） |
| 连击时限 | 4 秒内答对题目获得连击 +1，超时则连击数重置为 0（§12 D17） |
| 伤害公式 | **答对一题 = 一次暴击，伤害 = 武器攻击力 × 200%**（§12 **D8**）；小怪兽持有**活力值**，归零即被击败。基础武器（攻击力 100，每发 200）下击败所需答对数：普通 1 / 大怪 3 / BOSS 10；**武器升级提高攻击力 → 每发伤害提高 → 击败同一敌人所需答对数减少（BOSS 不再恒定 10 题）** |
| 单词补充 | 词池剩余单词数 < 10 时，自动从玩家选择的词库中补充 10 个新单词 |
| 波次结构 | **每局固定 5 波小怪兽，每局仅 1 只 BOSS 怪（第 5 波出现）** |

**波次配置**：
- 配置方式：通过 LevelConfig ScriptableObject 定义
- 字段说明：
  - totalWaves: int（总波次数）
  - waves: WaveData[]（每波小怪兽配置）
  
**WaveData 结构**：
- waveNumber: int（波次编号）
- zombieTypes: Dictionary<ZombieType, int>（小怪兽类型→数量）
- spawnInterval: float（小怪兽刷新间隔，单位：秒）

**波次配置示例**：
```
wave[0] = {
  waveNumber: 1,
  zombieTypes: {Normal: 5},
  spawnInterval: 2.0
}

wave[3] = {
  waveNumber: 4,
  zombieTypes: {Boss: 1, Normal: 5},
  spawnInterval: 3.0
}
```

**胜利判定流程**：
1. 每帧检测顺序：先检测失败条件，再检测胜利条件
2. 如果能量墙耐久值 <= 0：立即触发失败流程（即使场上无小怪兽）
3. 如果当前波次 == 总波次 且 场上小怪兽数 == 0 且 能量墙耐久值 > 0：触发胜利流程
4. 边界情况：耐久值刚好为 0 时，以失败判定为准
5. 单词补充：词池单词不足时自动补充，不影响胜利判定（胜利条件仅与波次和能量墙耐久值相关）

**失败处理流程**：
1. 检测到能量墙耐久值 <= 0
2. 立即暂停所有小怪兽行为（停止移动、停止攻击）
3. 播放失败动画（2 秒）：能量墙崩塌特效，所有小怪兽化为绿色雾气消散
4. 显示失败界面：“能量墙被摧毁，避难所失守！”
5. 结算奖励：根据击败小怪兽数计算 50% 奖励
6. 返回主界面

**波次递增规则**：
- 当前波次 = 正在刷新的小怪兽波次编号（从 1 开始）
- 波次切换条件：当前波次的所有小怪兽满足以下任一条件
  * 被击败（答对题目造成致命伤害）
  * 到达能量墙位置并开始攻击能量墙（视为“突破防线”）
- “突破防线”定义：小怪兽移动到能量墙位置后停下，不再继续前进，开始攻击能量墙
- 波次间隔：5 秒
- 示例：wave[1] 有 5 只小怪兽，3 只被击败，2 只到达能量墙开始攻击，则本波处理完毕，等待 5 秒，wave[2] 开始刷新

**能量墙耐久机制**（全场唯一失败数值）：

| 小怪兽类型 | 攻击行为 | 攻速 | 每次伤害 |
|---------|------------|------|---------|
| 普通小怪兽 | 到达能量墙前停下攻击 | 2 秒/次 | -5 耐久 |
| 大怪兽 | 到达能量墙前停下攻击 | 1.5 秒/次 | -5 耐久 |
| BOSS 怪 | 到达能量墙前停下攻击 | 1 秒/次 | -10 耐久 |

**能量墙耐久值规则**：
- 每局初始耐久 = 能量墙**当前阶位上限**（1 阶 100 … 5 阶 500，见 §2.4.3）；不跨局继承，每局开始重置为满值
- 耐久 <= 0 → 能量墙被摧毁 → **立即失败**（不存在“第二段伤害打到避难所”的设定）
- 小怪兽攻击能量墙时，其他小怪兽继续前进（不受影响）
- 小怪兽移动方向：从屏幕左侧向右侧移动，到达能量墙位置后停下攻击

#### 2.3.4 连击系统

**连击判定规则**：
- 连击数 = 当前连续答对的题目数量
- 连击时限：4 秒内答对题目获得连击 +1（§12 D17：由 3 秒延长，提升可达性）
- **连击计时衰减口径（v2.9 定案，审核项 A-14）**：补给三选一等**战斗暂停期冻结连击计时、不衰减**；**波与波之间的间隔（默认 5s、`Logistics` Doctrine −1s）期间连击计时继续走表**，若间隔内未答对致超时则连击重置为 0（守本条字面）。
- 超过 4 秒未答对：连击数重置为 0
- 答错或超时：连击数重置为 0

| 连击数 | 触发效果 | 作用范围 |
|--------|----------|----------|
| 3 连击 | 词汇连击 buff | 下次答对连射两枪：对当前小怪兽造成 **2 次暴击伤害**（活力 −2×攻击力×200%）+ 对距离防线最近的另一只小怪兽造成 1 次暴击伤害 |
| 5 连击 | 手雷 buff | 立即释放手雷，对半径 300 像素圆内小怪兽各造成一次暴击伤害（低活力者直接击败） |
| 8 连击 | 激光 buff | 立即释放直线激光，对所有触碰小怪兽各造成一次暴击伤害 |
| 12 连击 | 榴弹 buff | 立即释放榴弹，对半屏小怪兽（屏幕宽度的 50%）各造成一次暴击伤害 |
| 20 连击 | 核弹 buff | 立即释放核弹，对全屏小怪兽造成足以直接击败普通怪的巨额暴击伤害 |
| 全连击 | 战斗英雄称号 | 本地通报（本局结算面板展示 + 写入本地纪录），获得特殊奖励（整局未中断连击） |

> **连击 buff 与 §12 D8**：以上 buff 均折算为**暴击伤害实例**削减活力值；普通小怪兽（活力 200）通常一击即被击败，大怪/BOSS 需累计多次。**这些 buff 均由“答对达到连击数”触发，属“答题唯一击败”范畴；技能包伤害亦遵循同一铁律（§12 D8/D16）——不存在脱离答对的自动/持续掉血。**

**范围单位定义**：
- "3m" = 300 像素（1m = 100 像素，可在 GameConfig 中配置）
- "半屏" = 屏幕宽度的 50%（横向范围）
- "全屏" = 屏幕宽度的 100%

**3 连击 buff 规则**：
- 触发时机：下次答对题目时
- 目标选择：击败当前正在作答的小怪兽 + 距离防线最近的另一只小怪兽
- 如果没有其他小怪兽：只击败当前小怪兽，buff 浪费
- 视觉效果：连射两枪，分别命中两个目标

**全连击成就判定**：
- 条件：整局战斗中连击数从未重置为 0
- 即：从第 1 题到最后 1 题，全部在 4 秒内答对
- 奖励：获得"战斗英雄"称号，本地通报（结算面板展示 + 写入本机最高纪录），获得 100 能量晶

### 2.4 防御系统

#### 2.4.1 避难所机制
- **避难所本体：无血量、无耐久值、不可被攻击**（主程已定案）——它只是能量墙背后的美术与叙事对象
- **失败唯一来源**：词汇能量墙耐久值归零（§2.3.3）
- **核心建筑**：自动哨塔、词汇能量墙（防线数值主体）、急救补给站、预警瞭望台
- **资源类型**：词汇能量晶（**唯一货币**，仅游戏内产出、不可充值）、武器碎片（升级材料）
  > ⚠️ **v2.9 归一**：旧版出现的“金币”系输入错误，与“能量晶”为同一货币；全文不再存在第二货币。

#### 2.4.2 自动哨塔（支持 5 阶升级）

| 等级 | 射速 | 覆盖范围 | 特殊效果 |
|------|------|----------|----------|
| 1 阶 | 0.3 发/秒 | 正前方 120° | 子弹命中小怪兽使其减速 10%，持续 1 秒 |
| 2 阶 | 0.5 发/秒 | 180° | 智能锁敌，优先瞄准最近小怪兽 |
| 3 阶 | 0.5 发/秒 | 180° | 双倍弹仓，连续射击 4 秒不停火，减速效果提升至 20% |
| 4 阶 | 0.8 发/秒 | 360° | 双哨塔布局，左右各一座 |
| 5 阶满级 | 1.0 发/秒 | 360° | 解锁词汇能量子弹，20% 概率减速 30%，持续 2 秒 |

#### 2.4.3 词汇能量墙（支持 5 阶升级 · 防线数值唯一主体）

> 能量墙耐久值就是本局的**失败判定数值**（§2.3.3）；避难所没有独立血量。升级能量墙 = 提高本局初始耐久上限 + 解锁控制效果。

| 等级 | 耐久上限 | 控制效果 | 特殊能力 |
|------|--------|----------|----------|
| 1 阶 | 100 点 | 小怪兽触碰停顿 0.8 秒 | 无（原“消耗能量晶应急修复”已移除；战斗中不得消耗能量晶恢复耐久，见 §12 Q8） |
| 2 阶 | 200 点 | 停顿 1.5 秒 | 静止 3 秒后自动恢复 10 点耐久 |
| 3 阶 | 300 点 | 冻结 2 秒 | 随机弹出答对单词，触碰小怪兽被冻结 |
| 4 阶 | 400 点 | 冻结 2 秒 | 分段式结构，部分被击破不影响整体 |
| 5 阶满级 | 500 点 | 击退 1 米 | 每 10 秒释放词汇冲击波，击退 3m 内小怪兽 |

**4 阶「分段式」边界**：仅指**视觉分块与受击反馈**（某段破损后其余段仍显示），**耐久值仍是单一全局数值**；耐久归零即整墙摧毁并判负，不存在「分段各自判定失败」的逻辑。

#### 2.4.4 辅助建筑

**急救补给站**：
- 触发条件：单局内累计答对 50 道单词题（计数器每局游戏开始时重置为 0）
- 修复效果：恢复 20 点能量墙耐久
- 修复方式：自动触发（无需玩家操作）
- 升级效果：解锁“答题修复”，每连续答对 5 题自动恢复 5 点耐久（单局累计）
- 修复上限：不超过当前阶位的**耐久上限**（1 阶 100 / 5 阶 500）；已满载时不溢出、不转存
- 数据存储：GameData.correctAnswersInBattle（唯一计数字段）

**预警瞭望台**：
- 提前 5 秒提示下一波小怪兽数量和类型
- 满级后标记大怪兽位置，可优先集火高威胁目标

#### 2.4.5 敌人进攻
- **进攻方式**：波次进攻（每局 5 波，每波普通小怪兽 ×3-8，从可用种类中按 §12 D23 抽取；非 BOSS 波随机 1-2 只大怪兽，BOSS 波固定携带 2 只大怪随从）
- **敌人类型（活力值与 D8 伤害公式见 §12 / 附录 B）**：
  * 普通小怪兽（原型 `Normal`，下设 15 种独立骨架种类）：活力 200，基础武器下答对 1 次击败，掉落基础奖励
  * 大怪兽（原型 `Elite`，下设 10 种）：活力 600，基础武器下需答对 3 次击败，每局中随机 1-2 只出现在非 BOSS 波次（BOSS 波另有 2 只随从），掉落双倍奖励
  * BOSS 怪（原型 `Boss`，下设 5 种）：活力 2000，**每局仅 1 只，在第 5 波（最后一波）出现**，基础武器下需答对 10 次击败，掉落 = 附录 D 公式 5 晶 + 首通“稀有道具×1”一次性（数值后期按爽感调整，v2.9 归一审核项 A-05）
- **种类（species）口径（§12 D23）**：30 种敌人均为本体骨架、每种独立 Spine 骨架；种类名录与逐种数值由主策划 Phase 2 出表，种级别外观/数值走 `ZombieSpeciesConfig` 数据层配置，**不新增 `ZombieType` 枚举值**（3 类原型框架不变）

**击败判定与伤害规则**（§12 **D8**：答对=暴击，伤害=武器攻击力×200%）：
- 每答对一题：**当帧**对当前小怪兽结算一次暴击（伤害 = 武器攻击力 × 200%）并播放命中/击杀表现（§12 D17 即时命中，取消原“停顿 1 秒后继续前进”的硬等待）；其活力值按该伤害扣减，推进由 §12 D15（v2.6 修订：全程正常速度推进、不减速，锁定目标高亮）统一控制
- 答错或超时：不造成伤害，小怪兽停顿 1.5 秒后继续前进（活力值不恢复；此为有意的负反馈，保留）
- 活力值归零：小怪兽被击败，掉落奖励
- 到达能量墙：小怪兽开始攻击能量墙（不再响应答题，活力值判定结束）
- **击败所需答对次数 = ⌈活力值 ÷（当前武器攻击力×200%）⌉**：基础武器（攻击力 100）下普通 1 / 大怪 3 / BOSS 10；武器升级后该次数减少，故大怪/BOSS 绑定的多个单词可能未全部用到即被击败（剩余单词本题不出现，属正常）
- 哨塔等防御建筑仅提供减速/冻结/预警等**控制辅助**，**不削减小怪兽活力值**（答题是唯一击败手段，核心循环不变）
- **技能包同理（§12 D8/D16）**：控制类包（冰雪/减速/混乱）**不造成任何伤害**，只延长走廊可答时间；转化类包（闪电/散射/穿透/火焰）把**一次答对触发的暴击**扩散/贯穿到额外目标——**所有伤害实例均由“答对”触发，包本身不产生自动/持续掉血**

### 2.5 特色玩法

> 创新融合英语学习与塔防策略

**核心特色**：
1. **7 日记忆法系统**：将科学记忆方法融入游戏，生词入库→7日轮回复习→错题回溯→词库分层解锁
2. **连击 buff 系统**：连续答对触发不同级别强力攻击（**3/5/8/12/20 连击**，门槛下调与窗口延长见 §2.3.4 / §2.6 D17）
3. **随机特殊补给**：满足条件时触发局外空投补给包，玩家三选一（冰雪包/减速包/闪电包/混乱包/散射包/火焰包/穿透包）
4. **错题回溯机制**：答错单词自动归档，生成临时复习队列，强化薄弱环节
5. **难度动态适配**：连续 3 局正确率超过 90%，自动提升小怪兽刷新速度
6. **防线建筑升级**：自动哨塔和词汇能量墙支持 5 阶强度升级，策略深度丰富

### 2.6 战斗手感·策略·成长增强规格（§12 D17 / D18 / D19）

#### 2.6.1 战斗手感与连击节奏（D17）

**A1 即时命中（去卡手）**：
- 答对 → **当帧**结算暴击伤害并播放命中/击杀表现，取消“停顿 1 秒”的强制位移等待（见 §2.4.5）。
- 受击表现为**表现层硬直动画 `HitStunSeconds = 0.3`**（仅动画，不参与位移/结算，可与下一题出题重叠）。
- 当前锁定目标的前进由 **D15**（v2.6 修订：全程正常速度推进、不减速、锁定目标高亮）统一处理；世界不因答题而暂停或减速。
- 答错/超时保留 **1.5 秒停顿 + 嘲讽**（有意负反馈）。

**A2 连击门槛下调 + 窗口延长**（权威表见 §2.3.4，此处为口径说明）：
- 连击窗口 `ComboWindowSeconds = 4.0`（原 3.0）；可被补给/武器效果延长（`ComboWindowSeconds += comboWindowBonus`）。
- 档位由 **3 / 5 / 9 / 17 / 33** 调整为 **3 / 5 / 8 / 12 / 20**（效果不变，仅门槛下调），使半屏/全屏 AOE 在 BOSS 连答后半程自然可达。
- 所有连击伤害仍为“答对触发的暴击实例”，守 D8/D16 铁律。

**A3 迅捷作答奖励（技巧表达）**：
- 定义 **Swift**：单题**用时 ≤ `SwiftThresholdSeconds = 3.0` 且答对** → 该次暴击伤害 **× `SwiftDamageMultiplier = 1.15`**。
- Swift 增伤与会心一击 / 连击处决**加算叠加**，仍受“单次伤害不超过目标当前活力”约束；答错/超时不触发。计时起点复用现有出题计时器。

#### 2.6.4 目标高亮与稀有游走奖励怪（§12 D15 修订 / D20）

**D15 修订：目标高亮与推进（v2.6）**：
- **取消**旧“当前锁定目标答题期不前进、恢复推进 30% 减速”机制。**锁定与非锁定敌人全程均按各自基础速度正常推进**，答题界面显示期间世界不暂停、不减速，以提升流畅度与体感。
- **当前锁定答题目标**头顶显示醒目**高亮环**，答题框与该目标之间绘制**指示连线/箭头**；非锁定目标不高亮。仅表现层，不影响结算与位移。
- 后果与对策：大怪/BOSS 的时间窗只由**控制类技能包（冰雪/减速/混乱）与减速塔**延长（D16），时间收益成为过关核心资源；`Logistics` Doctrine（波间隔 −1s、掉落 +1）价值上升。触发/停止几何（1/6、4/6）与走廊窗口不变（附录 D）。数值 Phase 2 真机回校（R3）。

**D20 稀有游走奖励怪（增加趣味，Phase 3）**：
> **铁律**：不新增 `ZombieType`（守 D3/D23，种扩张走 `ZombieSpeciesConfig` 数据层、不加枚举值），以 `EnemyModifier.Wanderer` + `ZombieConfig`（外观/掉落）实现，与 D18 变体同机制。

| 名称 | 枚举组合 | 外观 | 掉落（`ZombieConfig.dropOverride`） | 刷出概率 |
|------|----------|------|-------------------------------------|----------|
| **金库怪 Gold**（“很有钱”） | `EnemyModifier.Wanderer` + 原型 `Elite` | 钱袋/宝藏造型、金光 | 能量晶 **20–40** | 每关 **5%** |

> 设计目标：把“认词→变强→更爽”从隐性、滞后的长线反馈，改成**当帧可感、屏幕可见**的即时反馈，让英语弱势玩家因“想更爽”而主动认词。三项效果均**不新增伤害来源**（伤害只由“答对”触发，守 D8/D16），只做**表现、奖励、阈值节奏**三件事。

**M1 生词上膛可视化（把词库进度画成弹药进度）**：
- 敌人头顶的词汇标记除现有光圈颜色外，叠加该词**记忆强度进度**（读现有 `LearningSystem` 的 `WordMasteryLevel` + 连续量 `MemoryStrength ∈ [0,1]`，见 Architecture §6.8）：

| 词状态 | 头顶显示 | 直观含义 |
|---|---|---|
| Unlearned（生词） | `?? 待解锁`（冷灰） | 还没上膛 |
| Learning | `上膛中 {int(MemoryStrength*100)}%`（蓝） | 压膛中，越熟越满 |
| Mastered / LongTermMastered | `满膛 ✓`（暖金） | 满膛，答对更易触发 Swift |

- 纯表现层：仅用现有掌握度数据，不改答题/伤害逻辑；`MemoryStrength` 为曲线强度归一化，Phase 1 若无连续量则以四态映射 0 / 0.5 / 0.8 / 1.0 兜底。

**M2 首次攻克新词 / 错题的即时爽奖励（Learning Spike）**：
- 触发条件（在“答对”结算同帧）：**首克新词**（该词在本账号**首次达到 Mastered**）；**攻克错题**（该词**从错题本被移出**时的那次答对）。
- 效果：① 屏幕“解锁新词 / 收复错题”爆字 + Swift 级命中特效 + 轻震；② 额外一次性能量晶 `FirstMasterCrystalBonus = 3` / `WordFixCrystalBonus = 2`（走 §4.4 奖励、**非伤害**）。
- 防刷：每词“首克里程碑”全局一次性（记 `PlayerData.masteredRewardSet`）；“攻克错题”按每次真正移出错题本结算一次，回到错题本后可再次触发。
- 合规：纯游戏内产出、不涉广告与内购（Compliance §3）。

**M3 掌握度→火力的可见连携（Mastery Meter，仅本局、守 D9）**：
- HUD 新增 **`Mastery Meter`（弹药熟练度条，0–100%）** = 本局已出题中“已掌握/长期掌握”词的占比；分档给**节奏增益**（只动阈值、不动伤害）：

| Meter | 本局增益（可叠加） |
|---|---|
| ≥60% | Swift 阈值 +0.5s（`SwiftThresholdSeconds` 3.0→3.5，更易触发 ×1.15） |
| ≥80% | 连击窗口 +0.5s（`ComboWindowSeconds` 4.0→4.5） |

- 若 100%（本局出题全为已掌握词，典型=复习/错题关）则两档常驻。闭环：认得多且熟 → Meter 高 → Swift/连击更易 → 更爽 → 复习/认词动机↑（把“温故”直接变“更猛”）。
- 运行时挂点：`BattleModifiers.swiftThresholdBonus` / `BattleModifiers.comboWindowBonus`（与 D18 Doctrine 同一运行时结构，仅本局生效、不写存档）；由 `MasteryMeterService.Percent` 每出题刷新。

**阶段与校准**：M1/M2/M3 首发排 **Phase 3**（M3 UI 可与会话 D 的 HUD 同批）；`FirstMasterCrystalBonus/WordFixCrystalBonus`、Meter 阈值与加成值 Phase 2 真机校准（并入 R3）。与 D17/D18/D19/D20 并存，冲突以本节口径为准。

#### 4.1.4 单词补充机制

**单词使用规则**：
- 普通小怪兽对应至多 1 个单词题目（基础武器下答对 1 题即造成致命暴击 → 击败）
- 大怪兽对应至多 3 个不同单词题目（基础武器下连续答对 3 题击败；武器升级可能提前用不完）
- BOSS 怪对应至多 10 个不同单词题目（基础武器下连续答对 10 题击败）
- 答对题目：对当前小怪兽造成一次暴击（伤害=攻击力×200%）削减活力值，单词从词池中移除（本局不再出现）；活力值归零则小怪兽被击败
- 答错/超时：单词进入错题本或超时记录，不造成伤害（活力值不变），停顿后继续前进

**题目映射方式**（大怪/BOSS 怪）：
- 从词池中按顺序抽取对应数量的单词（大怪 3 个、BOSS 怪 10 个）
- 依次展示给玩家，一题答完立即进入下一题（目标不切换）
- 中途小怪兽到达能量墙后：停止后续题目刷新，直接开始攻击能量墙

**单词补充触发条件**：
- 当词池中剩余单词数 < 10 时，自动触发补充机制
- 补充数量：从玩家选择的词库中随机抽取 10 个新单词
- 补充来源：优先从**上一局错词**（本局开始前记录的上局答错单词）中抽取，其次从已掌握单词中抽取，再次从待复习单词中抽取，最后从未学习单词中抽取
- 补充时机：在下一只小怪兽刷新前完成补充

**单词补充流程**：
```
1. 检测词池剩余单词数
2. if (剩余单词数 < 10) {
3.   从玩家选择的词库中随机抽取 10 个新单词
4.   优先级：上一局错词 > 已掌握单词 > 待复习单词 > 未学习单词
5.   将新单词加入词池
6.   后续小怪兽使用新单词
7. }
```

**单词补充时机**：
- 检测时机：每只小怪兽刷新前检测词池剩余单词数
- 补充时机：如果剩余 < 10，立即补充 10 个新单词
- 影响范围：补充的单词用于后续刷新的小怪兽（包括当前波次和下一波次）
- 示例：wave[1] 刷新第 3 只小怪兽前，检测到词池剩余 8 个单词，立即补充 10 个，则第 3 只及后续小怪兽使用新词池

**单词补充示例**：
```
初始词池：50 个单词
关卡进行到第 30 只小怪兽时，词池剩余 8 个单词
触发补充机制：从词库中随机抽取 10 个新单词
词池更新：8 + 10 = 18 个单词
后续小怪兽继续使用词池中的单词
```

**特殊关卡单词规则**：
- 7 日复习关：优先从 7 日记忆库中抽取待复习单词
- 错题回溯关：从错题本中抽取单词，答错不扣耐久值
- 普通关卡：从玩家选择的词库中随机抽取

### 4.2 战斗规则
<!-- 参考文档：战斗流程.txt -->

#### 4.2.1 回合机制
- **回合开始**：新一波小怪兽刷新，预警瞭望台提示小怪兽数量和类型
- **玩家阶段**：小怪兽进入答题圈，弹出单词考题，玩家选择答案
- **敌人阶段**：小怪兽向避难所推进，答错则小怪兽继续前进
- **回合结束**：本波小怪兽全部击败或突破防线，结算本波奖励

#### 4.2.2 答题规则

| 规则项 | 说明 |
|--------|------|
| 题目类型 | 英语单词释义题（单词→中文释义 / 中文→单词拼写） |
| 答题时限 | 默认 10 秒，可手动调整 10-20 秒区间（**仅在战斗开始前可修改**，进入战斗后不可调整） |
| 连击时限 | 4 秒内答对获得连击 +1（§12 D17） |
| 答对效果 | 自动触发一次暴击射击（伤害=攻击力×200%），削减当前小怪兽活力值（普通怪基础武器下直接击败；大怪/BOSS 需连续答对多次），该单词从词池移除；击败时掉落词汇能量晶 |
| 答错效果 | 单词立即进入错题本并从词池移除，小怪兽停顿 1.5 秒并跳出嘲讽气泡“就这？就这？”，屏幕显示该单词的释义和拼写提示，刷新 new 题目（下一只小怪兽的新单词） |
| 超时效果 | 等同于答错：单词进入超时记录并从词池移除，小怪兽停顿 1.5 秒并跳出嘲讽气泡，显示释义提示，刷新 new 题目 |
| 连击判定 | 4 秒内连续答对触发连击 +1，答错或超时均重置连击数（§12 D17） |

**答题时限修改规则**：
- 可修改时机：仅在战斗开始前（关卡选择界面 → 设置弹窗）
- 不可修改时机：战斗中（包括未暂停、已暂停、退出确认框都不可修改）
- 修改方式：设置滑块（10-20 秒）
- 生效方式：下一局开始时使用新的时限（当前局不可修改）
- 数据存储：PlayerData.answerTimeLimit

**延迟期间小怪兽行为**：
- 正在被守卫者攻击的小怪兽（当前正在显示答题界面的小怪兽）：停顿 1.5 秒（延迟期间不移动、不攻击）
- 其他小怪兽：不受影响，继续向能量墙前进
- 延迟结束后：
  * 如果小怪兽未到达能量墙位置：从当前位置继续向能量墙移动
  * 如果小怪兽已到达能量墙位置：立即开始攻击能量墙
- 补给包使用：延迟期间可正常使用补给包，效果立即生效
- **当前锁定答题目标推进（§12 D15 v2.6 修订）**：锁定与非锁定敌人**均按各自基础速度正常推进**（取消“不前进/30% 减速”）；当前锁定目标以**高亮环 + 指示连线**标记（§2.6.4）。买时间仅由控制类技能包 / 减速塔提供（D16）

**答错后单词处理规则**：
- 单词去向：立即从词池移除，进入错题本（后续会重新出现）
- 小怪兽行为：停顿 1.5 秒后继续向能量墙前进（不再对应任何单词）
- 后续触发：该小怪兽到达能量墙后直接攻击能量墙，不再触发答题界面
- 错题复习：错题本中的单词在后续关卡或 7 日复习关中重新抽取

**跳过/换题规则**：
- 跳过题目：不允许（必须作答或等待超时）
- 换题机制：不允许（每只小怪兽对应的题目固定）
- 原因：确保玩家真正掌握单词，而非逃避难题
- UI 实现：不显示跳过按钮或换题按钮（完全隐藏），避免玩家产生“可以跳过”的误解

**退出游戏规则**：
- 战斗中退出：视为失败，根据击杀小怪兽数计算 50% 奖励
- 计算公式：最终奖励 = 基础奖励 × 0.5（基础奖励根据击杀小怪兽数计算，不适用星级系数）
- 退出方式：
  * 按 ESC 键（PC）
  * 点击暂停按钮 → 退出关卡
  * 手机返回键 → 弹出确认框
- 确认框内容：“确定退出吗？当前进度将按失败结算”
- 确认后：返回主界面，本局数据按失败处理
- 固定奖励：不获得（退出时不获得重复奖励）
- 示例：击败 10 普通 + 2 大怪 + 1 BOSS 怪
  * 基础奖励：10×1 + 2×2 + 1×5 = 19 能量晶
  * 最终奖励：19 × 0.5 = 9.5 → 10 能量晶

#### 4.2.3 特殊补给系统（参考《向小怪兽开炮》随机技能选择）

**补给包掉落方式**：
- 掉落触发：满足掉落条件时，在局外触发空投动画
- 空投动画：补给包从屏幕上方掉落至屏幕中央（1.5 秒动画）
- 自动打开：补给包落地后自动打开，弹出三选一界面
- 战斗暂停：补给包选择期间战斗暂停（时间冻结；连击计时一并冻结、不衰减，见 §2.3.4 A-14）

**补给包掉落规则**：
- 每波小怪兽刷新时：30% 概率掉落 1 个补给包（触发时机：每波第一只小怪兽出现时）
- 每答对 5 个单词：必定掉落 1 个补给包（计数器跨波次累计，不重置）
- BOSS 波开始时：必定掉落 1 个补给包（**且必为控制类**，§12 D16）
- **关卡保底（§12 D16）**：每关前 3 波内**至少各掉落 1 个控制类与 1 个转化类**；随机池未命中时按保底补足（杜绝“脸黑必输”）

**补给包掉落计数器**：
- 计数器类型：跨波次累计（整局游戏持续计数）
- 计数规则：每答对 1 题，计数器 +1
- 掉落触发：计数器达到 5 的倍数时，立即掉落 1 个补给包
- 计数器重置：不重置（持续累计）
- 示例：答对第 5、10、15、20...题时各掉落 1 个补给包
- 数据存储：GameData.correctAnswersInBattle（**本局答对计数唯一字段名**，禁止另造 correctAnswerCount / correctAnswerCountInBattle）

**补给包持续时间**：
- 计时起点：玩家选择补给包后立即生效
- 持续时间：从生效时刻开始计算（数值可通过配置表调整）
- 计时结束：效果消失，补给包进入冷却
- 未使用作废（§12 Q3 定案）：玩家选择后若未在持续时间内触发效果（未射击命中），时间照常流逝、到期即作废，**不结转、不返还**（保留“过期作废”，**不**改为“获得即触发”）（**例外，§12 D16**：控制类可跨波囤积（至多 1 个）不受此限；转化类维持过期作废）

**补给包效果范围**：
- 中心点：以词汇守卫者获得补给包后第一次射击的小怪兽为中心
- 范围形状：半径 200 像素的圆形区域
- 范围配置：通过 SupplyPackConfig.effectRadius 可调整
- 示例：冰雪包冻结该中心点 200 像素半径内的所有小怪兽

**补给包叠加规则（§12 D16）**：
- 同时生效数量：**最多 2 个持续效果类**（**1 控制类 + 1 转化类**），支持“先冻 BOSS、再 AOE 群怪”组合技
- 同类互斥：新选择同类包会替换该类当前生效的包（例如两张控制包不叠）
- 即时效果类（闪电包）：立即触发，不占用持续槽
- 控制类可**跨波囤积，至多 1 个**（选后未立即使用不随波次清空，§12 D11 例外）；转化类维持“过期作废”
- 数据存储：PlayerData.activeSupplyPack → PlayerData.activeSupplyPacks[]（按类别各存至多 1，长度 ≤ 2）

**即时效果补给包规则**：
- 使用次数：无限制（每次掉落都可使用）
- 冷却时间：无冷却（立即触发）
- 触发时机：玩家选择后立即对目标小怪兽释放闪电链
- 叠加规则：可与持续效果类补给包同时生效
- 示例：玩家可以在冰雪包生效期间使用闪电包

**全屏范围定义**：
- 全屏 = 屏幕宽度的 100%（横向范围）
- 像素值：根据设备分辨率动态计算（例如：1920×1080 分辨率下，全屏 = 1920 像素）
- 中心点：仍以第一次射击的小怪兽为中心
- 示例：减速包 Lv3 以目标小怪兽为中心，半径 = 屏幕宽度/2 的圆形区域
- 配置方式：SupplyPackConfig.fullScreenRadius = Screen.width / 2

  * 如果补给包持续时间结束仍未射击：补给包消失，效果浪费

| 混乱包 | 回退时间 +50%（从 3 秒 → 4.5 秒） | 回退时小怪兽互相伤害 |
| 散射包 | 分裂子弹数 +2（从 3 个 → 5 个） | 分裂子弹数 +4（从 3 个 → 7 个）+ 穿透效果 |
| 火焰包 | 灼烧伤害 +50%（每秒伤害从 10 → 15） | 灼烧范围 +50%（半径从 200 像素 → 300 像素） |
| 穿透包 | 穿透数 +2（从 1 个 → 3 个） | 穿透数 +4（从 1 个 → 5 个）+ 伤害递增（每穿透一个小怪兽，伤害 +10%） |

**策略选择**：
- 玩家可根据当前关卡特点选择升级不同类型的补给包
- 例如：小怪兽密集关卡优先升级散射包；BOSS 关卡优先升级穿透包
- 补给包等级独立计算，玩家可自由搭配策略

**技能包策略层（§12 D16：必用设计）**：

> 战场几何（附录 D）下答题为串行（一次只锁一个目标），而敌人并行推进。**不使用技能包，大怪/BOSS 与多目标波次必然推线**——技能包是把“串行答题”转化为“并行/延时”的策略杠杆，而非可选增益。

- **分类**：控制类（不造成伤害、买答题时间）= 冰雪/减速/混乱；转化类（伤害仍由“答对”触发、串行变并行）= 闪电/散射/穿透/火焰
- **伤害来源铁律（§12 D8）**：所有伤害实例（含连击 buff 与转化类补给）均由“答对”触发；技能包本身不产生自动/持续掉血
- **目标推进与高亮（§12 D15 v2.6 修订）**：答题界面期间与恢复阶段，锁定与非锁定敌人均正常速度推进；当前锁定目标高亮标记（§2.6.4）
- **掉落保底**：每关至少 1 控制 + 1 转化；BOSS 波必掉 1 控制（叠加在既有随机掉落之上的保底池）
- **囤积**：控制类可跨波囤积，至多 1 个（§12 D11 例外）；转化类维持过期作废；同时生效放宽至 1 控制 + 1 转化
- **豁免关卡**：**教学关（第一章 1-1~1-4 无 BOSS 关）、7 日复习关、错题回溯关不启用“必用包”**，维持无惩罚/宽松；“不用包必被推”只作用于普通关与 BOSS 关
- **广告红线（Compliance §3）**：过关所需技能包**只能通过游戏内掉落获得**；激励视频**不得**作为“不看就必输”的必需包来源，仅可提供非必需增益

#### 4.2.4 波次规则

**波次结构总览**（每局固定 5 波）：

| 波次 | 敌人配置 | 特殊规则 |
|------|----------|----------|
| 第 1 波 | 普通小怪兽 ×3-5 | 无大怪，新手熟悉阶段 |
| 第 2 波 | 普通小怪兽 ×4-6 + 随机 1-2 只大怪 | 大怪首次亮相 |
| 第 3 波 | 普通小怪兽 ×5-7 + 随机 1-2 只大怪 | 中盘加强 |
| 第 4 波 | 普通小怪兽 ×6-8 + 随机 1-2 只大怪 | 高压阶段 |
| 第 5 波（BOSS 波） | 普通小怪兽 ×5 + BOSS 怪 ×1 + **大怪 ×2** | 本局唯一 BOSS；标准携带 2 只大怪随从（`Shielded`+`Mender`，经 §2.6.2 B2 `BossPressure`，Phase 3）；同时刷新 5 只普通小怪兽作为陪衬 |

**BOSS 触发规则**：
- 触发时机：**固定第 5 波（最后一波）出现 1 只 BOSS 怪**
- 每局仅 1 只 BOSS（无多 BOSS 关卡）
- BOSS 波编成：第 5 波同时刷新 5 只普通小怪兽 + 2 只大怪随从（Shielded/Mender）
- 示例：wave[5] = {boss: 1, elite: 2, normal: 5}

**大怪触发规则**：
- 大怪出现波次：第 2-4 波（随机 1-2 只）**与第 5 波 BOSS 波（固定 2 只随从）**（v2.9 归一审核项 A-04：旧“BOSS 波无大怪”作废，以 BossPressure 为 BOSS 波标准）
- 大怪数量：每波随机 1-2 只（概率：1 只 50%、2 只 50%）
- 第 1 波保证无大怪（新手保护）
- 示例：wave[2] = {elite: Random(1,2), normal: 5}

**小怪兽数量确定方式**：
- 通过 LevelConfig.waves 数组直接指定每波具体配置（非随机）
- 示例：关卡 1-1 配置
```
totalWaves: 5
waves: [
  {waveNumber: 1, zombieTypes: {Normal: 3}, spawnInterval: 1.5},
  {waveNumber: 2, zombieTypes: {Normal: 4, Elite: 1}, spawnInterval: 2.0},
  {waveNumber: 3, zombieTypes: {Normal: 5, Elite: 1}, spawnInterval: 2.0},
  {waveNumber: 4, zombieTypes: {Normal: 6, Elite: 2}, spawnInterval: 2.5},
  {waveNumber: 5, zombieTypes: {Normal: 5, Boss: 1}, spawnInterval: 3.0}
]
```

**击败所需答题数（基础武器下，§12 D8）**：
- 普通小怪兽（活力 200）：基础武器答对 1 题
- 大怪兽（活力 600）：基础武器连续答对 3 题（同时仅一只大怪兽在答题，答对一题后下一题不切换目标）
- BOSS 怪（活力 2000）：基础武器连续答对 10 题（同上）
- 武器升级提高攻击力 → 每发暴击伤害（攻击力×200%）提高 → 上述次数减少（BOSS 不再恒定 10 题）

**多阶段小怪兽处理**：
- 大怪兽与 BOSS 怪处于“答题中”状态时，不会同时弹出其他小怪兽的题目
- 只有当前小怪兽被击败 / 到达能量墙后，才会处理下一只小怪兽的题目
- 新到达能量墙的小怪兽：直接开始攻击能量墙，不再响应答题
- **游走奖励怪（§12 D20）为可选目标**：不推进、不攻墙，**不计入“本波小怪兽全部击败即波次完成/通关”的判定**；波次结束时若仍存活则直接消散（不惩罚、不奖励；仅在玩家点击锁定并答题击败时给掉落）

### 4.3 防御规则
<!-- 参考文档：避难防线.txt -->

#### 4.3.1 防线规则（能量墙为唯一数值主体）
- **耐久上限**：能量墙 1 阶 100 点（随阶位提升至 5 阶 500，见 §2.4.3）
- **避难所本体不持有数值**，不可被直接攻击；耐久归零 = 能量墙摧毁 = 失败
- **修复机制**：能量墙耐久**仅靠急救补给站恢复**（战斗中不得消耗能量晶修复，见 §12 D2/Q8）；不存在避难所血量修复
- **升级机制**：使用词汇能量晶升级自动哨塔和词汇能量墙（1-5 阶）

#### 4.3.2 敌人规则
- **刷新机制**：每波固定数量，波次间隔 5 秒
- **进攻路线**：从屏幕左侧向右侧直线推进
- **攻击行为**：到达能量墙位置后停下，开始攻击能量墙（不再继续前进）
- **优先级**：普通小怪兽匀速推进，大怪兽移动速度+20%，BOSS 怪移动速度-30% 但基础武器下需答对 10 次击败

**小怪兽移动速度定义**（`PIXELS_PER_METER = 100`，与附录 B / 附录 D 一致）：
- 基础速度：**1.0 m/s = 100 像素/秒**（可在 GameConfig 中配置）
- 普通小怪兽：1.0 m/s（匀速）
- 大怪兽：1.0 × 1.2 = **1.2 m/s（120 像素/秒）**
- BOSS 怪：1.0 × 0.7 = **0.7 m/s（70 像素/秒）**
- 减速效果：速度 × (1 - 减速百分比)
- 急速变体（§12 D18）：普通 × 1.5 = **1.5 m/s（150 像素/秒）**
- 游走奖励怪（§12 D20）：进入答题圈后**不推进**、在走廊 `[1/6, 4/6]` 内随机走走停停，**永不攻墙、不阻塞通关**（详见 §2.6.4）

**小怪兽攻击能量墙规则**：
- 触发条件：小怪兽到达能量墙位置（屏幕右侧防线）
- 攻击行为：停下移动，开始攻击能量墙
- 攻速和伤害：
  * 普通小怪兽：2 秒/次，每次 -5 耐久
  * 大怪兽：1.5 秒/次，每次 -5 耐久
  * BOSS 怪：1 秒/次，每次 -10 耐久
- 其他小怪兽：不受影响，继续向能量墙前进
- 击败小怪兽：答对题目使活力归零后，小怪兽被击败，停止攻击

### 6.4 关卡奖励

#### 6.4.1 奖励计算规则

**核心原则**：根据已击杀的小怪兽数量获得奖励（无论胜利或失败）

**奖励计算统一公式**：
```
最终奖励 = 基础奖励 × 奖励系数

基础奖励：根据实际击杀小怪兽数量计算（包含普通/大怪/BOSS 怪）

奖励与星级合并表（胜利时适用星级系数，失败时固定 0.5）：
| 结果 | 星级 | 条件 | 系数 |
|------|------|------|------|
| 胜利 + 高表现 | ★★★ | 耐久百分比 > 80% 且 答对率 > 90% | 1.5 |
| 胜利 + 中表现 | ★★☆ | 耐久百分比 > 50% 且 答对率 > 70% | 1.2 |
| 胜利 + 低表现 | ★☆☆ | 通关关卡（耐久值 > 0）| 1.0 |
| 失败 | 0 星 | 耐久值 <= 0 | 0.5 |

示例：
- 胜利获得 3 星：基础奖励 × 1.5
- 失败（耐久归零）：基础奖励 × 0.5（不适用答对率）
```

**单只小怪兽奖励**：

| 小怪兽类型 | 能量晶 | 武器碎片 |
|---------|--------|----------|
| 普通小怪兽 | 1 | 0.5 |
| 大怪兽 | 2 | 1 |
| BOSS 怪 | 5 | 3 |

**星级系数**（仅胜利时适用）：

参见上方【奖励与星级合并表】，胜利时适用：★★★ 1.5 / ★★☆ 1.2 / ★☆☆ 1.0；失败固定 0.5（不适用星级判定）

**耐久百分比计算**：
```
耐久百分比 = (当前耐久值 / 耐久上限) × 100%

其中：
- 当前耐久值：本局结束时剩余的耐久值（受攻击减少，受修复增加）
- 耐久上限：**直接等于能量墙当前阶位映射值**（1 阶 100 / 2 阶 200 / 3 阶 300 / 4 阶 400 / 5 阶 500，见 §2.4.3）；
  急救补给站**只恢复当前耐久值，不提升上限**（与 §2.4.4 / Architecture `IWall.Repair` 一致）

示例：能量墙 3 阶→耐久上限 300 点，本局结束剩 240 点，则耐久百分比 = 240/300 × 100% = 80%
```

**答对率计算规则**（§v2.9 定案：分母 = **本局实际首次出题数**）：
```
首次出题数（分母）= 本局内“首次出现”的题目总数（每个单词仅按首次出现计 1 次；答错/超时后同一单词重试不重复计入分母）
           = 首次答对题数 + 首次答错题数 + 首次超时数
答对题数（分子）= 本局首次作答即答对的题目数（一次答对计 1）

公式：答对率 = (首次答对题数 / 首次出题数) × 100%

重要说明：
- **旧口径废弃**：原分母为“初始词池数量”，但初始词池常大于本局真正会出的题量，导致三星（>90%）数学上几乎不可达（v2.8 审核项 A-02）；v2.9 改为“本局实际首次出题数”后，答对率 = 玩家首次作答的真实正确率，三星可达。
- 未从词池出题的剩余单词**不计入分母**；后续补充的单词也不单独计入分母（仅在同一单词首次已计基础上不重复）。
- 击败数与答对题数不等价（下列为**基础武器**下数值，武器升级后大怪/BOSS 所需答对数减少，§12 D8）：
  * 击败 1 只普通小怪兽 = 答对 1 题
  * 击败 1 只大怪兽 = 答对 3 题（不同单词）
  * 击败 1 只 BOSS 怪 = 答对 10 题（不同单词）
- 奖励区分：
  * 星级判定（答对率）：首次答对题数 / 本局实际首次出题数
  * 击败奖励（能量晶/碎片）：实际击败的各类小怪兽数
- 答对率上限：最多为 100%（首次答对题数不可能超过首次出题数，因重试不重复计入分母）
- 失败时：固定 0 星，奖励系数 0.5（不适用答对率判定）
- 数据来源：
  * GameData.questionsIssuedFirstTimeInBattle（本局实际首次出题数，每首次发出一题 +1；v2.9 新增，取代旧 initialWordPoolCount 作为星级分母）
  * GameData.correctAnswersInBattle（每首次答对一题，计数器 +1）

示例：
- 本局共 5 波，包括：普通小怪兽 ×25、大怪兽 ×2、BOSS 怪 ×1
- 首次出题数（分母）= 40（本局实际发出的不同题目数）
- 玩家首次答对 36 题（普通 20 + 大怪 2×3 + BOSS 1×10）、首次答错/超时 4 题
- 答对率 = 36/40 × 100% = 90%（不再因“分母=初始词池 50”而被拖低至 72%）
- 耐久值剩余 85%（>80%）且答对率 ≥90% → 三星★★★（边界例；若答对率严格计 36/40=90% 未超 90%，则归 ★★☆，阈值取“>”还是“≥”由 GameConfig 单点配置）
```

**单词与小怪兽对应关系（基础武器下）**：
- 普通小怪兽：对应 1 个单词题目（答对 1 题造成致命暴击 → 击败）
- 大怪兽：活力可支撑至多 3 个单词题目（基础武器连续答对 3 题 → 击败；武器升级可能提前用不完）
- BOSS 怪：活力可支撑至多 10 个单词题目（基础武器连续答对 10 题 → 击败）
- 答对题目：对当前小怪兽造成一次暴击（伤害=攻击力×200%）削减活力值，单词计入“答对题数”
- 答错/超时：不造成伤害（活力值不变、未被击败），单词计入“错题本”或“超时记录”
- 不补充新小怪兽：关卡的小怪兽总数固定，不会因为答错而刷新新小怪兽
- 示例：关卡 1-1 有 5 只小怪兽，对应 5 个单词。玩家答对 3 题，答错 2 题，则 3 只小怪兽被击败，2 只小怪兽突破防线

**星级评价计算时机**：
- 战斗过程中：实时显示当前耐久百分比和答对率（UI 更新）
- 战斗结束时：根据最终数据计算星级
- 计算公式（答对率上限 100%，分母 = 本局实际首次出题数）：
  ```
  // 答对率 = min(100%, 首次答对题数 / 本局实际首次出题数 × 100%)
  if (耐久百分比 > 80 && 答对率 > 90%) return 3星;
  else if (耐久百分比 > 50 && 答对率 > 70%) return 2星;
  else if (胜利) return 1星;
  else return 0星（失败）;
  ```

**示例计算**：
```
玩家击杀：10 普通 + 2 大怪 + 1 BOSS
答对率：85%，耐久值剩余 60%
星级评价：★★☆

基础奖励：
- 能量晶：10×1 + 2×2 + 1×5 = 19
- 武器碎片：10×0.5 + 2×1 + 1×3 = 10

最终奖励（★★☆ 系数 1.2）：
- 能量晶：19 × 1.2 = 22.8 → 23
- 武器碎片：10 × 1.2 = 12
```

#### 6.4.3 重复奖励

**重复奖励规则**：
- 触发条件：重复通关已通关的关卡（非首通）
- 固定奖励：每次重复通关必得能量晶 ×5-10

- 失败时：不获得重复奖励（仅获得基础击杀奖励的 50%）

## 8. 美术风格

### 8.1 整体风格定位

| 色调 | 明亮暖色调为主，高饱和度 | 阳光蓝、希望绿、活力橙，营造积极向上的氛围 |

**参考作品**：
- 《向小怪兽开炮》：核心玩法参考，Q版小怪兽设计，轻松幽默的战斗风格
- 《植物大战小怪兽》：卡通化敌人设计，色彩明亮，适合全年龄段
- 《Angry Birds》：简洁可爱的角色设计，鲜明的色彩对比

### 8.2 角色设计

#### 8.2.1 玩家角色（词汇守卫者）
- **外观设计**：Q版写实角色，大头小身体比例（2-3 头身），穿着科技感蓝色装甲，手持词汇能量枪，面部表情可爱友好
- **动作设计**：
  - 待机：持枪站立，偶尔查看手臂上的词汇显示器，做出可爱的思考动作
  - 攻击：举枪射击，枪口发出蓝色能量光芒，身体轻微后坐力
  - 胜利：举枪庆祝，跳跃动作，能量晶飞入背包
  - **失败判定**：能量墙被小怪兽摧毁后直接失败，玩家角色无受伤动作
- **特效设计**：射击时枪口蓝色能量特效，连击时全身发出彩色光芒，表情变化丰富

#### 8.2.2 敌人设计（§12 D23：30 种独立骨架 · 三批递进）

敌人共 **30 种**（普通小怪兽 15 / 大怪兽 10 / BOSS 5），**每种均为独立 Spine 骨架本体**，按三批交付：**P1 交 9 种（小 5/大 3/BOSS 1）→ P2 交 11 种 → P3 交满 30 种**。种级别美术规格与批次排期真源见 [美术资源需求表.md](./美术资源需求表.md) §3；种类名录与逐种数值由主策划 Phase 2 出表。

**三类原型外观基准**（品质档基准，各species在此之上做独立设计）：

| 敌人原型 | 外观特征 | 动作特点 | 设计元素 |
|---------|----------|----------|----------|
| 普通小怪兽（Normal，15 种） | Q版卡通形象，绿色系皮肤但可爱，穿着破烂但搞笑的衣服，表情呆萌；每种独立轮廓与配色识别 | 缓慢行走，身体摇晃，动作滑稽；每种独有待机/行走/受击/击败动画 | 绿色小雾气粒子、大大的眼睛、呆萌表情 |
| 大怪兽（Elite，10 种） | 体型稍大，紫色装饰，戴着夸张的文字碎片帽子；每种独有主题造型 | 移动速度+20%，偶尔做出搞笑的冲刺动作 | 紫色光晕、文字碎片环绕、自信的表情 |
| BOSS 怪（Boss，5 种） | 巨型但可爱，红色装饰，全身文字符文闪闪发光；每种独有巨型主题设计 | 移动速度-30%，活力 2000（基础武器下答对 10 次击败，D8 口径），动作缓慢但有趣 | 红色光晕、地面轻微震动、符文闪烁、搞笑的BOSS表情 |

**敌人设计原则**：
- 不恐怖、不血腥，适合全年龄
- 表情呆萌可爱，被打败时有搞笑的消散动画
- 颜色鲜明，易于区分不同类型与种类
- **品质优先（D23）**：每种敌人骨架按完整品质档制作（专属动作集 + 独立图集页），不为包体牺牲美术品质；机制变体仍以 `EnemyModifier` 叠加（D18），不占用种名额

#### 8.2.3 NPC 设计
- **商人**：Q版写实角色，穿着科技斗篷，背着鼓鼓的道具包，表情友好热情，在主界面商店入口
- **引导 NPC**：可爱的机器人形象，圆形身体，蓝色发光眼睛，提供新手引导，动作滑稽
- **词库管理员**：学者形象，戴大眼镜，手持发光的电子书，表情温和，在词汇档案室

#### 10.2.2 战斗系统

**状态机设计（v2.9 归一：以 Architecture.md 为真源）**：

> 顶层 `BattleState` 枚举的**唯一真源是 [Architecture.md](./Architecture.md) §3**：`{ Loading, Running, Paused, Victory, Defeat, Quit }`（接口契约，Phase 0 后签名不可改）。旧版本文列出的 9 个细粒度态**降级为 `Running` 的内部子状态机 `RunningPhase`**，不再作为顶层 `BattleState`。

```csharp
// 顶层（真源=Architecture §3，不变）
public enum BattleState { Loading, Running, Paused, Victory, Defeat, Quit }

// Running 内部子阶段（仅 BattleFlowController 私有状态机，不进公共契约/事件白名单）
public enum RunningPhase { Prepare, Spawning, Answering, Shooting, ComboCheck, WaveEnd }
```

**细粒度态 → 顶层 `BattleState` 映射**：

| 旧态（v2.8 前） | 归入顶层 | 说明 |
|---|---|---|
| Loading | `Loading` | 加载关卡场景 |
| Prepare / Spawning / Answering / Shooting / ComboCheck / WaveEnd | `Running`（由 `RunningPhase` 推进） | 单局战斗循环阶段；对外只暴露 `Running` |
| （补给三选一 / 手动暂停） | `Paused` | 冻结世界与连击计时（见 §2.3.4 A-14） |
| Settlement | → `Victory` / `Defeat` | 进入终态前的一次性结算过程 |
| End | `Victory` / `Defeat` / `Quit` | 退出确认→`Quit`；耐久归零→`Defeat`；波次清完→`Victory` |

> **实现约束**：`RunningPhase` 为 `BattleFlowController` 私有实现细节，**不新增 Architecture 公共枚举、不进事件白名单**；跨模块通信仍以顶层 `BattleState` + Architecture §5 事件（`WaveEndEvent`/`BattleEndEvent` 等）表达；UI/音效需更细时机时订阅既有事件而非轮询 `RunningPhase`。

public class QuestionManager {

    public Question GenerateQuestion(WordData word) {
        QuestionType type = Random.Range(0, 2) == 0 
            ? QuestionType.EnglishToChinese 
            : QuestionType.ChineseToEnglish;
        
        List<string> options = GenerateOptions(word, type);
        return new Question(word, type, options);
    }
    
    // 判定答案
    public bool CheckAnswer(Question question, int selectedIndex) {
        bool isCorrect = selectedIndex == question.correctIndex;
        if (isCorrect) {
            OnAnswerCorrect(question);
        } else {
            OnAnswerWrong(question);
        }
        return isCorrect;
    }
}

### 10.4 性能优化（2D 游戏专项优化）

#### 10.4.1 DrawCall 优化
- 目标 DrawCall：< 30（2D 游戏标准）
- 合批方式：
  - 静态合批：背景场景、固定建筑
  - 动态合批：小物体、道具
  - Sprite Atlas：所有角色动画、UI 图标打包成图集
- 材质合并：使用相同材质的 Sprite 合并渲染批次

#### 10.4.2 内存控制
- 目标内存：**≤ 400MB（§12 D23 修订：原 <150MB 随美术扩容放宽；低端机画质降级档兜底，真源 TechStack §9）**
- 纹理压缩：
  - Android：ASTC 4x4（6x6 用于背景大图）
  - iOS：ASTC 4x4（**不使用已弃用的 PVRTC**）
- 平台目标仅为 Android / iOS，**不存在 WebGL 分支**（内存/纹理策略不分三套写）
- 资源大小（2D Sprite）：
  - 角色动画：< 256x256 或 512x512
  - 场景背景：< 1024x1024 或 2048x1024（横版长图）
  - UI 图标：< 64x64 或 128x128
- 动画优化：使用 2D Animation 骨骼动画，减少序列帧

#### 10.4.3 帧率优化
- 目标帧率：**移动端 60 FPS 稳定**（中低端机允许 45 FPS 兜底，不得锁 30）；Editor PC 60 FPS（TechStack.md §18 为唯一真源）
- 2D 物理优化：
  - 使用 2D 物理系统（Rigidbody2D、Collider2D）
  - 小怪兽移动使用 Transform 直接移动，不使用物理
  - 碰撞检测简化为 2D 盒子碰撞
- 渲染优化：
  - 使用 2D Renderer（URP 2D）
  - 关闭不必要的 3D 渲染特性
  - 使用 Tilemap 管理场景地块
  - 屏幕外对象自动禁用（Frustum Culling）

#### 10.4.4 包体大小
- 目标包体：**≤ 200MB（单渠道安装包，含运行时；§12 D23 修订：突破原 <80MB 约束，200MB 为唯一硬线；与 TechStack.md §9 口径一致）**
- 资源压缩：
  - 音频：OGG 格式；BGM **128kbps 立体声（§12 D23 品质上调·全量重制，原 96kbps 单声道废除）**，音效/长音效 96kbps 单声道
  - 纹理：ASTC 压缩（全平台统一），2D Sprite 优化
  - 动画：优先使用骨骼动画，减少序列帧
- 代码混淆：ProGuard（Android）
- 词库数据：首发核心词库内置于安装包（D14），全额计入 200MB 包体（D23 修订：原“仅词库超 80MB 豁免”作废）；教材 DLC 按需下载

#### 10.4.5 2D 游戏专项优化

| 优化项 | 具体措施 |
|--------|----------|
| Sprite 渲染 | 使用 Sprite Mask 实现遮挡效果，避免多层渲染 |
| 动画系统 | 使用 Unity 2D Animation 骨骼动画，减少内存占用 |
| 粒子系统 | 限制最大粒子数 100 以内，使用 Simple Particle |
| 场景管理 | 使用 Scene Streaming 分块加载横版场景 |
| UI 优化 | Canvas 分离，避免频繁重建 |
| 对象池 | 小怪兽、子弹、特效全部使用对象池复用 |

#### 10.4.6 平台适配（2D 游戏）

| 平台 | 特殊处理 |
|------|----------|
| Android | 适配不同屏幕比例（16:9 / 18:9 / 20:9），Pixel Perfect + Safe Area |
| iOS | 刘海屏 / Dynamic Island 适配，Safe Area 处理 |
| PC Editor | 仅开发预览：键鼠操作、窗口化/全屏切换、分辨率自适应（**不发行 PC 包**） |

### D. 数值公式

#### 伤害计算（§12 D8：答对=暴击）
```
每发暴击伤害 = 武器攻击力 × 200%（基础武器攻击力 = 100 ⇒ 每发 200）
击败所需答对数 = ⌈敌人活力值 ÷ 每发暴击伤害⌉

基础武器（攻击力 100）下：
- 普通小怪兽：活力 200 → 答对 1 次击败
- 大怪兽：活力 600 → 答对 3 次击败
- BOSS 怪：活力 2000 → 答对 10 次击败

武器升级（攻击力↑）→ 每发伤害↑ → 大怪/BOSS 所需答对数下降（例：Lv.7 攻击力 200、每发 400，大怪 2 次、BOSS 5 次击败）
答错/超时不造成伤害；哨塔等控制建筑不削减活力值（答题为唯一击败手段）
```

#### 连击规则（§12 D17 已重调；权威表见 §2.3.4）
```
连击窗口 = 4 秒（原 3 秒）
3 连击：下次答对连射两枪
5 连击：手雷 buff（半径 3m）
8 连击：激光 buff（直线穿透）（原 9）
12 连击：榴弹 buff（半屏）（原 17）
20 连击：核弹 buff（全屏）（原 33）
```

#### 经济公式
```
关卡能量晶产出 = (击败普通小怪兽数 × 1 + 击败大怪兽数 × 2 + 击败 BOSS 怪数 × 5) × 星级系数
武器碎片产出 = (击败普通小怪兽数 × 0.5 + 击败大怪兽数 × 1 + 击败 BOSS 怪数 × 3) × 星级系数

星级系数：
- 胜利时：★★★ = 1.5, ★★☆ = 1.2, ★☆☆ = 1.0
- 失败时：0.5

建筑升级费用 = 建筑等级 × 50 能量晶（1阶→50, 2阶→100, 3阶→150, 4阶→200, 5阶→250）
  # 唯一真源 = GameConfig 升级价格表（本公式）；所有界面（§7.4 避难所/商店、结算预览）显示的建筑/词库/武器价格一律从此表读取，UI 与其它章节不得另写独立数字（v2.9 归一审核项 B-03）
词库解锁费用 = 词库阶段 × 200 能量晶（初中→200, 高中→400, 四六级→600）
```

**战场长度（按主流横屏 · `1m = 100px`）**：敌人从左侧出生，前进至**左起 1/6 处触发答题**，推进至**4/6 处停止并攻击能量墙**（4/6→6/6 为墙后避难所美术区）。

**可答题窗口 = 走廊长度 ÷ 移速**（附录 B 速度：普 1.0 / 大 1.2 / BOSS 0.7 m·s⁻¹）：

|---|---|---|---|

| BOSS | 13.7s | 17.1s | 50s ❌ 需控制包叠加 + 连击/AOE |

> **必用包依据（§12 D15 v2.6 修订后）**：全程正常推进 → 单只大怪（需 ~15s）已超其 8.0s 走廊窗口、BOSS 远超 13.7s，**不再靠“答题期冻结”兜底**；只能由**控制类技能包把目标钉在走廊内**争取时间，且波内其余敌人并行推进。故“不用技能包必被推、用包方可过关”进一步成立，控制包与 `Logistics` Doctrine 的时间收益成为过关核心资源（Phase 2 真机回校节奏与保底数量，见 R3）。

**战斗时长（目标 5–10min）**：单局时长 ≈ 总答对数 × 单题周期（常规~5s）+ 波间隔(4×5s) + 首波推进(~5s)。5min≈52 题、8min≈84 题、10min≈108 题；转化类包把一次答对打到多目标会**缩短**实际时长，需与波次密度、掉落节奏联动校准。

**经济校验（附录 D 公式为唯一真源）**：标准关（34 普 + 5 大 + 1 BOSS）基础能量晶 = 34×1+5×2+1×5 = **49**（★★★ 73.5 / ★★☆ 58.8）；主线 15 关一周目 ≈ 700–820 晶，够解锁全部词库(1200)约六成、建筑满级(3000)约两成，中期需 replay（建议 replay 倍率 50%）。**§6.1 固定首通奖励与附录 D 公式量级一致，以公式为准；§6.1 仅作“首通额外一次性奖励”叠加，不得双轨实现。**
