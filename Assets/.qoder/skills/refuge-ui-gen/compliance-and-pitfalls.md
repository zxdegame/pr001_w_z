## 2. UI 已知坑（评审 / 自测优先排查）
- **TMP 缺字豆腐块**：字体子集须含全部用到的字符；符号走 `ic_*` 精灵，**禁系统 emoji 直显**。
- **Canvas 层塞错**：Popup 内容放进 Gameplay 层 → 遮挡顺序 / 合批错乱；按语义归 `Background`/`Gameplay`/`Popup`。
- **绝对摆死**：按 1920×1080 手摆坐标 → 20:9 / 刘海溢出裁切；改 Layout Group + 锚点 + `SafeAreaView`。
- **命中区过小**：< 96×96px 或间距 < 24px → 儿童误触；答题键 ≥160×96px。
- **UI 写死数值**：时限 / 阈值 / 价格硬编码进脚本 → 取 `QuizConfig` / `GameConfig` SO。
- **跨系统直接引用**：view `GetComponent` 业务类或直改其字段 → 经 EventBus / provider 只读。
- **自造状态机**：在 UI 里另写一套答题状态 → 订阅 Architecture `QuizState`。
- **改接口绕过 RFC**：为“UI 要显示”往契约塞字段 → 先走 RFC，缺字段回主程拍板。
- **易变值写死**：guid / 版本号 / 渲染管线 guid（如 2D Renderer）/ 性能数值写进代码或本文档 → **运行时读文档头与实测取**。
- **可见文案旧词**：出现“僵尸 / 护盾 / 血量 / 击杀”→ 改档案词表（见 §1 敏感词行）。
- **命名 / 归位**：prefab `UI_<Name>.prefab` 归 `Assets/UI/<场景>/`，不散落 `Scripts`；`.panel` 资源同目录。
- **绑定名冲突活例**：UI.md 表写 `IWall.Durability/Max`，真源 `IWall.CurrentDurability`（详见 data-binding.md §1）。
